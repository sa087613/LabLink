# GT Lab Match
 
A web platform that helps Georgia Tech students find research opportunities. Students upload their resume, and the platform matches them with labs, professors, and research projects across campus based on their skills and interests.
 
## What it does
 
- Students upload a resume (PDF or DOCX)
- The platform parses the resume for skills, coursework, and experience
- Matches are generated against a database of GT labs and active research areas
- Students get a ranked list of labs to reach out to, with contact info and research focus
- Optionally, students can filter by department, keyword, or paid/unpaid status

## Why
 
Finding undergrad research at Georgia Tech is mostly word of mouth or cold-emailing professors with no idea if there's a fit. This closes that gap by doing the matching automatically.
 
## Getting Started
 
```bash
# clone the repo
git clone <repo-url>
cd gt-lab-match
 
# install dependencies
npm install   # or pip install -r requirements.txt
 
# run locally
npm run dev
```
